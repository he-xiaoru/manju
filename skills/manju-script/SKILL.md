# 漫剧剧本生成

把一句话题材扩展成可直接进入分镜阶段的 3 分钟漫剧剧本。剧本面向动态漫画拍摄，**画面提示词和台词同等重要**，不是纯文字对白稿。

## 1. 先定型，别急着写

动手前确认两件事，缺哪件就先问用户：

- **题材**：一句话说清世界观和核心爽点（例如「穿越到古代当厨子」）。
- **主角设定**：姓名、现代/古代身份、年龄外形、核心技能、性格标签或口头禅。

顺手定下本集的**一句话梗概**和**结尾钩子**。钩子决定第 4 场怎么写，先想好再动笔。

## 2. 按 3 分钟拆成 4 场左右

3 分钟 ≈ 170 秒，四场足够，最多五场。节奏按下面分配：

| 场次 | 作用 | 时长 |
| --- | --- | --- |
| 第 1 场 | 开场钩子，主角被逼到绝路 | 20–30 s |
| 第 2 场 | 主角第一次露一手 | 30–40 s |
| 第 3 场 | 冲突升级，反派上门 | 50–60 s |
| 第 4 场 | 反转打脸，抛出下一集钩子 | 40–50 s |

台词总量控制在 **400–600 字**（中文口播约每分钟 250–300 字）。900 字光念就要 3 分钟以上，画面就没地方了。参考密度：第 01 集约 510 字，第 02 集约 590 字；统计时记得把 `**角色**（动作）：台词` 这种带动作提示的行也算进去。每场至少留一个「静下来」的画面瞬间，给动态漫画做升格或特写用。

## 3. 每场写清场景、人物、画面、台词

每场用三级标题，标题里带时间码，例如 `### 第 1 场　穿越 · 灶房（0:00–0:25）`。正文四项：

- **场景**：地点、时间、氛围。
- **人物**：本场出场角色。
- **画面**：镜头与动作提示。写具体动作（「糖丝拉出半尺长」），不要写「他很震惊」这种抽象情绪。
- **台词**：角色名加粗，短句口语化；内心 OS 单独标注，用来承载现代梗和笑点。

## 4. 台词避开明清以后传入中国的食材

古代题材里出现这些就是出戏：**辣椒、番茄、土豆、红薯、玉米、花生、南瓜、菠萝、腰果**。它们都是明清或更晚才传入。

可放心使用的是：**蛋、米、面、猪肉、鸡鸭、鱼、山药、藕、白菜、萝卜、豆腐、冰糖、花椒、姜、葱、酱油**。

只有当题材本身是现代或架空、或用户明确要求时，才不受这条限制。

## 5. 输出

- **格式**：Markdown。结构依次为「角色设定」→「分场与台词」→「时长与节奏分配」→「道具与画面要点」。
- **落盘位置**：存进项目的 `剧本/` 目录，文件名 `第NN集.md`（两位数字，如 `第01集.md`）。
- **编码**：UTF-8 无 BOM，保证 GitHub 网页和普通编辑器都能正常显示中文。

## 参照范例

`剧本/第01集.md` 是按本规范产出的第一集（穿越到古代当厨子），可以作为结构与语气的参照。
