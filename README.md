# 漫剧项目

漫剧（动态漫画短剧）的制作工作区，用于集中管理剧本、分镜与素材，并跟踪它们的版本变更。

## 目录结构

| 目录 | 用途 |
| --- | --- |
| `剧本/` | 分集大纲、剧本正文、角色设定与台词 |
| `分镜/` | 分镜脚本、镜头表、画面构图与节奏说明 |
| `素材/` | 角色立绘、背景、音效、BGM、字幕等原始与成品资源 |

## 命名与版本约定

- 文件命名：`S01E01_场景名_v01.md`，修订时递增为 `_v02`，不覆盖旧版本。
- 素材大文件（视频、音频母带、PSD 工程等）不入库，统一走网盘或对象存储，仓库内只保留清单与链接。
- 剧本与分镜的改动分开提交，提交信息写清集数、场次与改动范围。

## 快速开始

1. 编剧在 `剧本/` 建立本集剧本。
2. 分镜师依据剧本在 `分镜/` 产出镜头表。
3. 美术与音效把成品放入 `素材/` 对应子目录。
